# COLMO AI 厨房共感

纯静态 HTML + CSS + JavaScript + Three.js 0.169.0。所有渲染依赖位于 `ai-3/vendor`，无 CDN 运行依赖。通过 HTTP 服务访问 `ai-3/`，无需构建。

## 已实现

- 可旋转和缩放的 3D 厨房；灶具、冰箱、烟机、蒸烤机状态热点；三个相机视角。
- 晚餐需求修改、方案确认、设备回执等待、烹饪、人工翻面确认、完成反馈。
- 手动接管与有回执的恢复；风险模拟、停止请求、停机回执、人工检查、显式恢复。
- P1/P2/P3 话术与动效变化；P3 常规过程静默，关键行动与风险仍播报。
- Dynamic line / Layered glass 切换；I1/I2/I3 动效参数；蓝白、琥珀、风险红、短暂成功绿。
- 70 段预合成男女声 MP3；点击开始有声晚餐即播报。声音与话术面板支持试听、音色选择、语速、音量、停止及逐节点话术查看。音频播放进度驱动动效，自动流程等待播报完成。
- 桌面/移动布局、减少动态效果偏好、标签页不可见时暂停渲染。

## 资料使用

节点以用户提供《AI归类表达方案_V4_连续编号统一配色(2).xlsx》的“节点归类索引”为准：N094/A2、N118/B5、N119/C1、N120/C1、N122/C3、N124/C4、N127/D1、N128/D2、N130/D4、N136/E1。辅助参考《AI场景归类框架与归类步骤(1).xlsx》的分类边界。两版编号不同，不混用。

两张用户截图用于光带与层叠玻璃动效参数：I1 35% / 12px / 6s；I2 65% / 40px / 2.5–3s；I3 95% / 76px / 1s。P3 的常规确认降低存在感，高风险不降级。

所有设备数据、回执、菜谱时序、库存与异常事件都是交互演示数据。未连接真实设备或大模型。资料与服务器凭据不包含在公开目录中。

## 部署

目标：`https://creaitor.cn/COLMO/demo/ai-3/`。
静态目录：`/www/wwwroot/creaite.cn/COLMO/demo/ai-3/`。
Nginx 仅添加 `deploy-ai-3.conf` 中的两个精确范围路由。全站备案由服务器注入，页面覆盖样式将其置于首屏之后。

## TTS 更新（2026-09-10）

参考用户提供的 COLMO 人设规范 PDF 与男女声标准 DOCX。参考资料仅供设计，未发布。男声采用 YunyangNeural，女声采用 XiaoxiaoNeural，均为演示合成音色，不是 COLMO 官方定制声线。音色生成基准语速分别为 -8% / -6%，页面倍速以此为基准。所有 MP3 已打包，访客播放不调用第三方语音服务。

`voice-content.js` 为播报稿单一来源；默认用餐条件使用具体话术，自定义条件使用引导核对屏幕的播报稿，避免播报过时人数或时间。`build-voices.py` 用于重新生成音频，`test-tts.mjs` 校验音频映射、打断、旧回调、错误与自动播放限制。70 个音频均通过 FFprobe 验证，约 2.8 MB。
