# COLMO AI 智能管家 Demo

按场景分别存放的静态 HTML / CSS / JavaScript / Three.js 交互演示。每个 `ai-*` 文件夹包含独立页面、模型代码、动效、话术、预生成音频和渲染依赖，可单独部署。

| 文件夹 | 场景 | 内容 | 在线体验 |
| --- | --- | --- | --- |
| [ai-1](ai-1/) | 晨间无感唤醒 | 31 节点、三任务协作流程、卧室与主卫 3D、床背与窗帘动效、人物动作、256 段男女声 | [打开](https://creaitor.cn/COLMO/demo/ai-1/) |
| [ai-3](ai-3/) | 厨房烹饪 | 晚餐方案、跨设备协作、确认与接管、风险分支、70 段男女声 | [打开](https://creaitor.cn/COLMO/demo/ai-3/) |

## 本地预览

在仓库根目录运行：

```sh
python3 -m http.server 8783 --bind 127.0.0.1
```

打开 http://127.0.0.1:8783/ai-1/ 或 http://127.0.0.1:8783/ai-3/ 。使用 HTTP 服务访问，不直接通过 `file://` 打开。预览无需安装 npm 包，也不需要 API 密钥；语音为随页面打包的 MP3，Three.js 在各场景的 vendor 目录。

## 检查

需要 Node.js，运行：

```sh
npm test
```

测试覆盖话术资源、播放状态、原表节点关联、动作时序及任务独立接管。

## 文件组织

```text
ai-1/                   晨间场景完整静态文件与说明
ai-3/                   厨房场景完整静态文件与说明
build-wake-voices.py     晨间及流程分支音频生成
build-voices.py          厨房音频生成
test-wake.mjs           晨间节点、动作与流程测试
test-tts.mjs            厨房语音与打断测试
deploy-ai-*.conf        对应场景 Nginx 路由示例
deploy-ai-*.sh          服务器端发布脚本
```

增加场景时新建 `ai-2/`、`ai-4/` 等独立文件夹，并补充此表。已有场景路径保持稳定。

## 音频与部署

重新生成音频需要 Python 的 `edge-tts`。生成脚本跳过已有 MP3；修改话术后，先移走对应旧音频再执行生成。男声 Yunyang、女声 Xiaoxiao 是合成演示音色，并非 COLMO 官方定制声线。

生产环境可将完整 `ai-1/` 或 `ai-3/` 作为静态目录部署。根目录的发布脚本针对现有服务器路径，运行前应核对目标路径和压缩包；脚本先备份，再校验 Nginx 配置并重载。仓库不包含 SSH 凭据、API 密钥或原始办公附件。

设备、传感器、用户状态、历史记录与回执均为模拟，不连接真实设备。各场景详细说明见对应文件夹 README。Three.js 的许可文件保留在各自 vendor/LICENSE。
