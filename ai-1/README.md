# COLMO 无感唤醒 3D Demo

线上地址：https://creaitor.cn/COLMO/demo/ai-1/

静态 HTML / CSS / ES modules + Three.js。`ai-1/` 为完整发布目录；不需要构建或服务端密钥。使用 HTTP 服务打开，不能直接 file:// 双击运行。现有本地预览：http://127.0.0.1:8783/ai-1/。

## 覆盖与交互

V4《AI归类表达方案》的「节点归类索引」N001—N031 全部映射到 source-nodes.js；保留原始分类、原始名称、行号和表达原则供页面查阅。环境预备 10 个、无感唤醒 11 个、洗漱备水 10 个。nodes.js 是逐节点话术和动作；room-state.js 是模拟设备状态；scene.js 是可旋转缩放的主卧与主卫几何模型。

「体验晨间流程」串联 16 个常规节点，必要操作确认后手动继续。异常、接管、事后复盘与长期优化是独立样例，通过完整目录或前后节点按钮访问。独立节点使用预置条件，切换节点不代表上一异常已经解除。拒绝方案或撤回试用会退出引导流程。

每节点包含 P1 / P2 / P3 三套初始话术和一套结果回执，两种声音共 248 段 MP3。语音以 COLMO 人设、对话规范和 TTS 人声标准为文案与表达方向，使用合成演示音色（男声 Yunyang、女声 Xiaoxiao），不是官方定制音色。音频已随页面打包，运行时无需第三方 TTS 请求。可切换声音、语速、音量，单独审听或选择逐节点讲解模式。场景模式在睡眠期保持静默。

光带与层叠玻璃使用参考图 I1/I2/I3 的亮度、弥散、周期、层数、层距和透明度范围。琥珀待确认，蓝白常态，保护回执后未解决异常持续红色；绿色仅普通成功回执后保持 1.8 秒。高风险不会因 P3 而弱化。

所有设备、历史记录、身份和回执均为模拟；模型不连接真实设备。清醒不能仅凭在床/离床推断；水温设定与实际出水区分；长期优化依赖预置多次记录，不将本次点击作为长期学习证据。

## 验证与维护

`node test-wake.mjs` 验证完整编号、248 个资源、静默、异常强度、停机状态及主流程边界。已用 ffprobe 检查全部音频可读、时长有效，并通过浏览器核验 3D、男女声、播放进度、异常回执、静默行为与手机布局。

`build-wake-voices.py` 为音频再生成脚本（需要 edge-tts），已有资源会跳过；变更文案时应先移走对应旧 MP3 再生成。`deploy-ai-1.sh` 是上传到服务器后执行的发布脚本，依赖 /tmp 中的 tar.gz 和路由配置。脚本先备份现有目录及独立 Nginx include，验证 Nginx 后重载；不更改 ai-3。

## 人物与设备动作（2026-09-10 更新）

模型新增两个人物骨架、使用者侧独立抬升靠背与可开启窗帘。模型下方「播放动作」提供 34 秒独立动作预演，支持暂停、进度拖动与重播：晨光进入 → 靠背抬升 32° → 坐起伸展 → 转身落脚站立 → 绕过玻璃隔断走向主卫 → 俯身抬手。伴侣一侧保持平躺，床背辅助为模拟已授权的可选演示，不更改原表规则或把人物动画当作清醒识别证据。切换节点将退出动作预演，恢复节点状态。播放动作时停止当前 TTS，避免原节点语音与独立动作冲突。

choreography.js 管理确定性时间轴；avatar.js 管理关节人物姿态与行走路线。test-wake.mjs 已补充动作先后顺序、终点姿态及风险节点不自动坐起的验证。

## 泳道流程融入

来源 https://creaitor.cn/colmo/flow/ 的 S1 AI晨间唤醒；读取 data.js 并核对服务器 overrides.json（本次为空）。flow-source.js 保留 7 个阶段/分支、48 个来源节点（34 个交互节点、14 条辅助说明）；flow-model.js 为 34 个交互节点提供到原有 N001—N031 的演示关联，不将流程能力分类冒充表达分类。

新增「协作流程」入口，按使用者、管理者、设备、AI中枢及需求/风险展示流程内容，点击关联编号可跳转 3D 节点。新增独立三任务协作样例：再睡五分钟仅暂停唤醒，本次不用热水仅停止本次水路，音箱离线保留异常。统一结果卡汇总三项状态，体感反馈只存于本页，不自动写入长期规则。增加 4 条管家反馈男女声，共 8 段音频；合计 256 段。原有 31 节点及 34 秒动作预演保留。
